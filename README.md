# Sales & Revenue Analysis Dashboard

# 📊 Project Overview

This project is an interactive Sales & Revenue Analysis Dashboard created using Microsoft Power BI Desktop.

The dashboard provides a clear overview of sales performance, profitability, orders, quantity, products, categories, and regional performance using the Superstore dataset.

# 🎯 Objectives

- Analyze overall sales and profit performance
- Identify top-performing products and categories
- Compare sales across different regions
- Analyze monthly sales trends
- Generate meaningful business insights from sales data

# 🛠️ Tools & Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX
- Superstore Dataset
- GitHub

# 📈 Dashboard Features

The dashboard includes:

- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Total Quantity KPI
- Monthly Sales Analysis
- Product-wise Sales Analysis
- Category-wise Sales Analysis
- Region-wise Sales Analysis
- Interactive Region Filter
- Interactive Category Filter
- Key Business Insights

# 💡 Key Insights

- West region leads in total sales.
- South region has comparatively lower sales.
- Technology is the top-selling category.
- Sales show a noticeable increase during August–October.
- The dashboard helps identify sales performance across products, categories, and regions.

# 🚀 How to Use

1. Download the Power BI template (`.pbit`) from this repository.
2. Open it using Power BI Desktop.
3. If required, provide the path to the Superstore dataset.
4. Refresh the data.
5. Use the filters and visualizations to explore the dashboard.
